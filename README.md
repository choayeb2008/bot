# 🖼️ بوت تحليل وتعديل الصور - Image Editor Bot

**بوت تلغرام متقدم لتحليل إعدادات التحرير من الصور وتطبيقها على صور أخرى**

## ✨ المميزات

- 📸 **تحليل ذكي للصور** - استخراج 8 إعدادات تحرير مختلفة
- 🎨 **تطبيق الإعدادات** - تطبيق نفس الإعدادات على أي صورة أخرى
- 🤖 **مدعوم بـ Google Gemini** - تحليل دقيق باستخدام الذكاء الاصطناعي
- ⚡ **سريع وخفيف** - بدون قاعدة بيانات، تخزين مؤقت في الذاكرة فقط
- 🌍 **واجهة عربية كاملة** - رسائل وتعليمات باللغة العربية

## 📋 الإعدادات المدعومة

البوت يحلل ويطبق 8 إعدادات تحرير:

1. **التباين (Contrast)** - -100 إلى +100
2. **السطوع (Brightness)** - -100 إلى +100
3. **التشبع (Saturation)** - -100 إلى +100
4. **الظلال (Shadows)** - -100 إلى +100
5. **الإضاءة (Highlights)** - -100 إلى +100
6. **درجة الحرارة اللونية (Color Temperature)** - 2000K إلى 8000K
7. **الحدة (Sharpness)** - 0 إلى 100
8. **التلاشي (Fade)** - 0 إلى 100

## 🚀 البدء السريع

### المتطلبات

- Python 3.8+
- حساب Google AI (للحصول على Gemini API Key)
- توكن Telegram Bot (من BotFather)

### التثبيت

1. **استنساخ المستودع**
```bash
git clone https://github.com/choayeb2008/bot.git
cd bot
```

2. **تثبيت المتطلبات**
```bash
pip install -r requirements.txt
```

3. **إعداد متغيرات البيئة**

قم بإنشاء ملف `.env` وأضف فيه:
```env
TELEGRAM_TOKEN=your_bot_token_here
GEMINI_API_KEY=your_gemini_api_key_here
```

4. **تشغيل البوت**
```bash
python main.py
```

## 📖 آلية الاستخدام

### للمستخدم:

1. ابدأ المحادثة مع البوت: `/start`
2. أرسل صورة محررة
3. سيعرض البوت الإعدادات المستخرجة
4. اضغط على زر "📸 نسخ التعديل على صورتي"
5. أرسل الصورة التي تريد تطبيق الإعدادات عليها
6. ستحصل على الصورة المعدلة مباشرة

## ⚙️ التخصيص

### تغيير نطاقات القيم:

في `image_processor.py`، عدّل الدالة `normalize_value()`

### تغيير رسائل البوت:

في `handlers.py`، عدّل متغير `WELCOME_MESSAGE`

### إضافة إعدادات جديدة:

1. أضف المفتاح الجديد في `ANALYSIS_PROMPT` في `gemini_handler.py`
2. أضف دالة معالجة جديدة في `image_processor.py`
3. استدعِ الدالة في `apply_edits()`

## 🐛 استكشاف الأخطاء

### المشكلة: البوت لا يستجيب

**الحل:**
- تحقق من توكن Telegram
- تحقق من الاتصال بالإنترنت
- تحقق من ملف السجل `bot.log`

### المشكلة: خطأ في Gemini API

**الحل:**
- تحقق من مفتاح API
- تحقق من حدود الاستخدام اليومية
- اطلب quota زيادة من Google

### المشكلة: الصورة المعدلة سيئة الجودة

**الحل:**
- عدّل قيم `normalize_value()` في `image_processor.py`
- جرب صور مختلفة للمقارنة
- قلل قيم التعديلات
